
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：央行名 / 统计机构名 / 交易所名 / 品种名 / 行业名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是数字 / 代码 / 没信息量的 teaser（如 "CPI"、"Gold Daily"、"Update"、"Breaking"）时，结合【来源】和正文把主体与动作补进标题。例：原标题 "Gold Daily" + 来源 "LBMA" → "LBMA 黄金定盘价 9 月 29 日报"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体指标或报告期时，用上位词（如"官方持仓报告""央行决议"）兜底，绝不凭"行业常识"编一个具体数字 / 报告期 / 机构。
5. 原标题表达的【文章类型和核心动作】是硬边界：Analysis / Comment / Outlook / Explainer / Review / Q&A 这类解读、评论、展望或科普标题，中文标题必须保留这个类型；不能因为正文谈到某个已公布的决定或数据，就改写成"降息""大涨""发布报告"。只有原标题明确宣布了决定、发布或发生，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、品种、报告期。
   例：原标题 "Gold: Softer Jobs Data Triggers Selling" → "就业数据走软引发黄金抛售"，不能写成 "美联储降息推动黄金上涨"。
   例：原标题 "Weekly Metals Digest" + 来源和正文明确是多家机构 → "多家机构周度金属综述"，不能写成 "铜价本周大涨"。
6. **合规**：标题不得出现目标价、买卖建议、仓位建议或无出处的方向断言。「金价大涨」要写成带基准的事实表述，如「金价日内涨逾 2%」；「黄金见顶」不得作为标题。
