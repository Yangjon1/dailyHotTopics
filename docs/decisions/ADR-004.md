# ADR-004: 选 lucide-react 作为全站唯一图标库，纯 SVG 描边

## Status: Accepted (2026-10-05)

## Background

团队 P0 绝对规则（由项目总监制定，适用于所有成员）：

1. **禁止 emoji 作为功能图标**
2. 禁止紫色→粉色渐变主视觉
3. 禁止 AI 模板味文案
4. **禁止硬编码颜色值**（唯一例外 `#fff` / `#000`）
5. **禁止弹跳缓动**

技术侧的任务是：**锁定一套纯 SVG 描边图标库，具体库由架构师选型，全项目统一不混用，尺寸 16/20/24px。**

选型约束：
- 必须是 SVG（不能用图标字体、不能用位图、不能用 emoji）
- 必须描边风格（`fill="none"` + `stroke`）以统一视觉
- 必须能tree-shake（`apps/web` 是 SSR，构建产物直接进Node）
- 必须兼容 React 19.3.0

## Decision

**全站唯一图标库 = `lucide-react` 0.544.0。尺寸只允许 16 / 20 / 24px，`strokeWidth` 固定 2，描边风格。禁止 emoji、禁止图标字体、禁止混用第二套图标。**

落地约束（写进 Spec，逐字实现）：

```tsx
// 尺寸与描边宽度定义为常量，全站import 这个，不写字面量
export const ICON = { sm: 16, md: 20, lg: 24 } as const;
export const ICON_STROKE = 2;

// 使用方式
import { TrendingUp } from "lucide-react";
<TrendingUp size={ICON.md} strokeWidth={ICON_STROKE} aria-hidden />
```

`lucide` 的默认属性即 `fill="none"` + `stroke="currentColor"`，天然满足描边要求，且颜色随Tailwind 文本色继承——从而**不会引入硬编码颜色值**。

## Consequences

### 正面

- 天然满足 P0「禁止 emoji 图标」：库里没有任何位图或字符
- `stroke="currentColor"` + Tailwind 的 `text-*` 类 → 图标颜色自动跟随文字色，**不违反「禁止硬编码颜色」**
- tree-shake 友好，只import 用到的图标
- 1500+ 图标覆盖金融场景所需（趋势、警报、货币、时间、数据库、外部链接等）
- 纯 SVG 组件，SSR 友好（`apps/web` 是 React Router SSR）——**不使用 `react-icons` 那类需要额外处理 `<svg>` 属性合并的方案**

### 负面

- 引入一个外部依赖（1500+ 图标，每个都是一个小文件，依赖体积不小——但 tree-shaking 后实际打进产物的只有用到的那些）
- lucide 的默认风格是「圆角、几何」，与某些金融终端风格的直角图标不完全一致——**统一性优先于风格偏好**

### 内嵌坑（必须写进 Spec）

**内嵌坑 1**：P0 规则要求「尺寸 16/20/24px」，但 lucide 默认是 24。**必须显式传 `size`**，不能依赖默认值，否则会出现 20/20/24 混杂的视觉不一致。

**内嵌坑 2**：`strokeWidth` 也要固定。lucide 默认 `strokeWidth={2}`，但如果有人为了「图标太粗」调成 1.5，**必须一起改全站**。所以要定义 `ICON_STROKE` 常量而不是各写各的。

**内嵌坑 3**：lucide 组件在 SSR 下会输出 `stroke="currentColor"`。**`currentColor` 在 Tailwind 的 `text-*` 上下文里才正确**。如果放在没有文字色的容器里（如 `bg-white` 无文字色类的 div），图标会渲染成黑色（`currentColor` 的初始值）——**注意包裹元素的文字色类**。

**内嵌坑 4**：lucide 的组件名是 PascalCase（`TrendingUp`），中文站若需要按业务语义组织，建议在 `site/brand/` 下建一个 `icons.ts` 做**语义化再导出**（`export { TrendingUp as IconGold }`），避免业务代码到处import 库名——但这层再导出**不得引入第二套图标**。

## Alternatives Considered

| 方案 | 评分（5分制） | 为什么拒绝/采纳 |
|---|---|---|
| **lucide-react 0.544.0** | 学习成本 低 / 生态 极好 / 风格一致性 **高**（单一描边风格）/ tree-shake 好 | [OK] **采纳** |
| `react-icons` 5.x | 学习成本 低 / 生态 极好 / 风格一致性 **低**（含 5 个风格包：Fa、Hi、Ri、Md、Bi） | [NG] 5 套风格极易混用，**直接违背 P0「全项目统一不混用」**。哪怕团队自律，人多也守不住 |
| Heroicons 2.x | 学习成本 低 / 生态 好 / 风格一致性 中（描边 + 实心两套）/ 图标数仅 ~300 | [!]️ 可用，但图标数不足以覆盖金融场景（缺货币、趋势细类、交易所类图标），且描边/实心两套也需要额外约束 |
| Radix Icons 15.x | 学习成本 低 / 生态 中 / 风格一致性 高（统一 15x15 网格描边） | [!]️ 视觉质量高、风格最统一，但生态与文档不如 lucide，金融领域图标覆盖不足 |
| 内联手写 SVG 组件 | 学习成本 **高** / 生态 无 / 一致性 全靠自觉 | [NG] 长期不可维护，违反「不做过度设计」也违反「不做临时方案」 |
| Material Symbols（可变字体） | — | [NG] 需引入字体文件 + `@font-face`，SSR 下还要处理字体加载闪烁，且是**可变字体**（非纯 SVG 组件） |
